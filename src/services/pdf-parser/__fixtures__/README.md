# PDF parser fixtures

이 디렉터리에는 가명으로 만든 합성 PDF만 커밋한다. 실제 카드 명세서 PDF와
실제 비밀번호는 절대 커밋하지 않는다.

사용하는 가명·테스트값은 `홍길동`, `123********99`,
`04524 서울특별시 중구 세종대로 110`, `010-1234-5678`, 비밀번호
`000000`, owner password `owner-secret-test`다.

다음 명령으로 세 픽스처를 다시 생성할 수 있다.

```sh
node scripts/make-pdf-fixtures.mjs
```

한글 폰트 의존성은 픽스처 생성 시점에만 있다. 생성된 PDF를 읽는 테스트와
프로덕션 PDF 파서는 시스템 폰트를 사용하지 않는다. 다른 폰트를 쓰려면
`FIXTURE_FONT` 환경 변수로 TTF/TTC 경로를 지정한다.
