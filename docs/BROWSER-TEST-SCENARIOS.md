# 브라우저 테스트 유스케이스 시나리오

finsight를 브라우저 자동화 도구(dev-browser 등)로 테스트할 때마다 참고하는 유스케이스 모음.
각 유스케이스는 독립적으로 실행 가능하도록 **목적 / 사전조건 / 단계 / 기대 결과**로 구성했다.
화면·문자열이 바뀌면 이 문서와 픽스처도 함께 업데이트한다.

---

## 공통 사전 준비

- **개발 서버**: `npm run dev` → 기본 `http://localhost:3000`
- **브라우저 모드**: 헤드리스가 아닌 일반 모드로 실행. UC-02(Google 로그인)는 사람이 직접 로그인해야 하므로 화면이 보여야 한다.
- **픽스처** (`docs/fixtures/`):
  - `test-transactions.csv` — PII 없는 정상 거래내역 (`거래일시,가맹점명,이용금액,업종`)
  - `test-transactions-with-pii.csv` — 이름/전화번호/카드번호 포함 (PII 처리 검증용)
- **LLM 프로바이더 주의**: `.env.local`의 `ANTHROPIC_API_KEY`가 비어 있으면 `src/services/llm/provider.ts` 폴백 로직에 의해 분석 호출이 항상 OpenAI(`gpt-5.1`)로 넘어간다. UC-04·UC-09 실행 전 실제 어떤 프로바이더가 호출되는지 확인할 것.
- **자격증명 원칙**: 자동화 스크립트는 어떤 경우에도 실제 Google 비밀번호를 입력하지 않는다. 로그인 입력은 사람이 수행한다.

## A. 인증 & 접근 제어

### UC-01. 신규 방문자가 랜딩 페이지를 본다
- **목적**: 비로그인 사용자에게 랜딩이 정상 노출되고 CTA가 로그인으로 연결되는지
- **사전조건**: 로그인되지 않은 세션
- **단계**
  1. `/` 접속
  2. `무료로 시작하기` 버튼 클릭
- **기대 결과**
  - Hero 문구 노출: `거래내역을 올리면,` / `새는 돈이 보여요.`
  - 3단계 안내(`1 CSV 업로드`, `2 컬럼 자동 매핑 확인`, `3 인사이트 확인`) 노출
  - 기능 비교: FREE(`카테고리별 합계`, `총 지출·거래 건수`, `가맹점 Top 5`) / PREMIUM(`전월 대비 증감` 등)
  - 신뢰 문구: `원본 CSV는 저장하지 않아요 …`
  - CTA 클릭 → `/login`으로 이동

### UC-02. 사용자가 Google로 로그인한다 (수동 개입)
- **목적**: OAuth 로그인 후 대시보드 진입
- **사전조건**: 로그인되지 않은 세션
- **단계**
  1. `/login` 접속
  2. **`Google로 계속하기`** 버튼 클릭 (`GoogleSignInButton.tsx`)
  3. ⚠️ 열리는 Google 화면에서 **사람이 직접** 계정 선택·로그인
- **기대 결과**
  - `signInWithOAuth({ provider: "google", redirectTo: "{origin}/dashboard" })` 흐름 진입
  - 로그인 완료 후 `/dashboard`로 리다이렉트

### UC-03. 미들웨어가 접근을 라우팅한다
- **목적**: `middleware.ts`의 세션 기반 리다이렉트 검증
- **케이스 A (비로그인 → 보호 페이지)**: 로그아웃 상태로 `/dashboard` 접속 → `/login`으로 리다이렉트
- **케이스 B (로그인 → 랜딩)**: 로그인 상태로 `/` 접속 → `/dashboard`로 리다이렉트
- **케이스 C (로그아웃 → 보호 페이지 재접근)**: 대시보드 헤더의 `로그아웃` 클릭 → `/login`으로 이동 → 뒤로가기나 주소창으로 `/dashboard` 재접근 시 다시 `/login`으로 리다이렉트(세션 쿠키가 실제로 지워졌는지 확인)

## B. CSV 업로드 & 매핑

### UC-04. 정상 CSV를 업로드하고 분석한다 (핵심 해피패스)
- **목적**: 업로드 → 컬럼 매핑 확인 → 분석 생성까지
- **사전조건**: 로그인 상태, 대시보드
- **단계**
  1. `/dashboard`에서 업로드 카드(`data-testid="upload-card"`, 제목 `거래내역 CSV 업로드`) 확인
  2. 파일 입력(`aria-label="CSV 파일 선택"`)에 `test-transactions.csv` 업로드 (드래그앤드롭도 가능)
  3. 매핑 카드(`data-testid="mapping-card"`, 제목 `컬럼 매핑 확인`)에서 날짜/가맹점/금액/카테고리 자동 매핑 확인
  4. **`분석 시작`** 클릭
- **기대 결과**
  - 업로드 중 `파일을 확인하고 있어요...` 표시
  - 매핑 셀렉트 자동 채움, 필수 필드 미충족 시 `분석 시작` 비활성
  - 분석 완료 후 `/dashboard/[analysisId]`로 이동
  - `다시 올리기`로 초기화 가능

### UC-05. PII 컬럼이 포함된 CSV를 올린다 (⭐ 보안 필수)
- **목적**: 이름·전화번호는 제외, 카드번호는 뒤 4자리만 남기는지 UI에서 확인
- **사전조건**: 로그인 상태
- **단계**
  1. `test-transactions-with-pii.csv` 업로드
  2. 매핑 카드의 PII 안내 문구 확인
- **기대 결과**
  - 제외 안내: `이름·전화번호는 전송되지 않았어요` (컬럼명은 `·`로 연결)
  - 마스킹 안내: `카드번호는 뒤 4자리만 남겼어요`
  - 원본 이름/전화번호/전체 카드번호가 화면·네트워크 요청 어디에도 노출되지 않아야 함 (개발자도구 Network 탭에서 `/api/upload` 응답 확인 권장)

### UC-06. 잘못된 파일을 올린다 (에러 처리)
- **목적**: 빈 파일·비정상 파일에 대한 에러 모달 노출
- **단계**: 빈 CSV 파일 또는 비정상 파일을 업로드
- **기대 결과**
  - 에러 모달(`ErrorModal`, 제목 `안내`, 닫기 버튼 `닫기`) 노출
  - 빈/누락 파일(`BAD_REQUEST`): `파일을 읽지 못했어요. CSV 형식을 확인해 주세요.`
  - 기타 서버 오류(500 등): `문제가 발생했어요. 잠시 후 다시 시도해 주세요.`
  - ⚠️ 알려진 한계: CSV 파싱 예외는 라우트에서 잡히지 않아 500으로 떨어질 수 있음(기대 동작 아님, 회귀 감시 대상)

## C. 인사이트 조회

### UC-07. Free 요약을 확인한다
- **목적**: 무료 사용자에게 계산·저장된 요약 카드 노출
- **사전조건**: 분석이 하나 이상 있는 로그인 상태
- **단계**: `/dashboard/[analysisId]` 접속 (섹션 `aria-label="무료 지출 요약"`)
- **기대 결과** — 다음 4개 카드
  - `총 지출` → `{금액}원`
  - `거래 건수` → `{n}건`
  - `카테고리별 합계` (`data-testid="category-card"`, 금액 내림차순)
  - `가맹점 Top 5` (번호 매긴 목록)

### UC-08. 미구독자가 Premium 리포트를 시도한다 (⭐ 페이월 필수)
- **목적**: 미구독 사용자에게 Premium 리포트가 **생성되지 않는지** 확인 (CLAUDE.md 규칙)
- **사전조건**: 구독하지 않은 로그인 계정, 분석 상세 페이지 (섹션 `aria-label="Premium 리포트"`)
- **기대 결과**
  - 4개 카드(`data-testid="premium-card-{type}"`)에 `PREMIUM` 배지 + **`Premium으로 보기`** 버튼만 노출
  - 리포트 본문·`리포트 보기` 버튼은 없음
  - `Premium으로 보기` 클릭 시 `POST /api/checkout`이 호출되고 Polar Hosted Checkout으로 이동하며, `/api/reports/...` 요청은 여전히 발생하지 않음
  - (API 직접 호출 시) 미구독자의 `/api/reports/...` 요청은 `403 PAYWALL_REQUIRED`로 거부되어야 함

### UC-09. 구독자가 Premium 리포트를 조회한다
- **목적**: 구독자에게 4종 리포트가 lazy-generate 되어 표시되는지
- **사전조건**: 구독 상태 계정, 분석 상세 페이지
- **reportType 키(언더스코어 주의)**: `mom_comparison`, `anomaly_detection`, `savings_suggestions`, `budget_recommendation`
  → 요청 경로: `/api/reports/{analysisId}/{reportType}`
- **단계**: 각 카드의 **`리포트 보기`** 버튼 클릭 (로딩 중 `불러오는 중...`)
- **기대 결과 (성공 시)**
  - `전월 대비 지출 변화` → `전월 대비 상세` 목록(전체 지출 + 카테고리별 증감%); 이전 분석 없으면 `비교할 이전 분석이 아직 없어요.`
  - `이상 거래·중복구독 탐지` → 요약 + `이상 거래 상세` 목록
  - `절약 제안` → `절약 제안 상세` 목록(제목 + 절약액)
  - `카테고리별 예산 추천` → `예산 추천 상세` 목록(추천 예산 + 현재 지출 + 사유)
- **에러 상태** (ErrorModal)
  - `403 PAYWALL_REQUIRED`: `이 리포트는 Premium 구독에서 확인할 수 있어요.`
  - `404 NOT_FOUND`: `요청하신 분석을 찾을 수 없어요. 다시 시도해 주세요.`
  - `502 GENERATION_FAILED`: `리포트를 생성하지 못했어요. 잠시 후 다시 시도해 주세요.`

### UC-11. 미구독자가 업그레이드하고 대시보드로 복귀한다
- **목적**: Hosted Checkout 진입부터 결제 복귀 안내와 웹훅 반영까지 확인
- **사전조건**: 구독하지 않은 로그인 계정, 분석 상세 페이지, 로컬에서는 `polar listen http://localhost:3000/api/webhooks/polar` 실행
- **단계**
  1. 잠금 카드의 `Premium으로 보기` 클릭 (`이동 중...` 표시, 4개 버튼 비활성)
  2. Polar 샌드박스 체크아웃에서 결제
  3. `/dashboard?checkout=success`로 복귀
- **기대 결과**
  - `결제가 완료됐어요` 배너 노출
  - 주소창에서 `?checkout=success`가 사라지고, 새로고침해도 배너가 다시 뜨지 않음
  - 웹훅이 이미 처리됐으면 `아래 업로드 이력에서 분석을 열면 Premium 리포트를 확인할 수 있어요.` 표시
  - 웹훅이 아직 처리되지 않았으면 `구독 반영까지 몇 초 걸릴 수 있어요. Premium 리포트가 아직 잠겨 있다면 잠시 후 페이지를 새로고침해 주세요.` 표시 후, 새로고침하면 Premium 잠금이 풀림
- **실패 시**: 체크아웃 생성 실패는 페이지 이동 없이 공용 ErrorModal의 `문제가 발생했어요. 잠시 후 다시 시도해 주세요.`로 표시

## D. 히스토리 & 네비게이션

### UC-10. 업로드 이력을 조회하고 상세로 이동한다
- **목적**: 히스토리 목록 노출 및 상세 진입
- **사전조건**: 로그인 상태
- **단계**: `/dashboard`의 이력 섹션(제목 `업로드 이력`) 확인 → 항목 클릭
- **기대 결과**
  - 비어 있을 때: `아직 업로드한 내역이 없어요 — CSV를 올려 시작해 보세요`
  - 항목 있을 때: 각 항목에 날짜(`YYYY. M. D.`, Asia/Seoul), 총 지출 `{금액}원`, 거래 건수 `{n}건` 표시
  - 각 항목은 `/dashboard/{id}` 링크 → 클릭 시 상세 페이지 이동
  - ⚠️ 파일명·카테고리 수는 표시되지 않음(현재 스펙)

## 부록: 참고 사항 / 알려진 한계

- **상세 페이지 소유권 미검증**: `dashboard/[analysisId]/page.tsx`는 소유권(user_id) 검사를 하지 않고 `getAnalysisById` 결과를 그대로 렌더한다. 소유권 검증은 리포트 API(`/api/reports/...`)에서만 수행됨. 다른 사용자의 `analysisId`로 상세 접근 시 동작을 회귀 감시할 것.
- **뒤로가기 링크 없음**: 상세 페이지에 대시보드로 돌아가는 링크/버튼이 없다. 브라우저 뒤로가기 또는 주소 직접 입력으로 이동.
- **파일 크기·행 수 제한 없음**: 업로드 라우트는 빈 파일(`size === 0`)만 거부하고 크기/행 수 상한은 없다. 샘플 미리보기만 5행으로 제한됨.

### API 계약 요약
`POST /api/upload` (`src/app/api/upload/route.ts`)
- multipart 필드명: `file`
- 미로그인 `401 UNAUTHORIZED` · 빈/누락 파일 `400 BAD_REQUEST`
- 성공 `200 { mapping, sample: { headers, rows, excludedColumns, maskedColumns } }`

`GET /api/reports/{analysisId}/{reportType}` (`src/app/api/reports/[analysisId]/[reportType]/route.ts`)
- 미구독 `403 PAYWALL_REQUIRED` · 없음/타인 소유 `404 NOT_FOUND` · 생성 실패 `502 GENERATION_FAILED`
