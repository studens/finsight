# PRD: finsight

## 목표
카드/은행 거래내역 CSV를 업로드하면 Claude가 분석해 지출 요약·이상거래·추이 등 개인화된 재무 인사이트를 제공하는 핀테크 SaaS.

## 사용자
- **지민 (직장인, 30대)**: 매달 카드값이 예상보다 많이 나오는데 어디서 새는지 모름 → 이상거래/중복구독 탐지에 지불 의사
- **재우 (프리랜서)**: 개인/사업 지출이 한 계좌에 섞여있음 → 정산/신고용 월별 추이 리포트에 지불 의사
- **은지 (신혼부부, 저축목표 있음)**: 여러 구독 서비스 중 안 쓰는 것을 못 찾음 → 이상거래/구독탐지에 지불 의사

재무 관리 툴을 처음 써보는 사람도 CSV 하나만 올리면 바로 결과를 볼 수 있어야 한다.

## 핵심 기능
1. Google OAuth 로그인 → 대시보드 진입
2. CSV 업로드 → 컬럼 자동 매핑(사용자 확인) → PII 마스킹 → Claude 분석으로 Free 요약 생성 (동기 처리, 인메모리)
3. **Free (무료·무제한)**: 카테고리별 지출 합계, 총 지출/거래 건수, 가맹점 Top 5
4. **Premium (구독 필요, 지연 생성)**: 전월 대비 증감, 이상 거래·중복구독 탐지, 절약 제안, 카테고리별 예산 추천 — Free 사용자에게는 잠금 카드로 노출해 업그레이드 유도
5. 업로드 이력 대시보드 — 마스킹된 분석 결과를 저장해 재방문 시 과거 분석을 다시 볼 수 있고, "전월 대비" 계산의 기준이 됨
6. 구독 상태 기반 기능 게이팅 (`subscriptions` 엔타이틀먼트 스키마까지만 이번 phase에 포함. Polar 실제 체크아웃/웹훅 연동은 계정 준비 후 별도 `polar-billing` phase)

## 검증 가설
- **H1 (PLG)**: 무료 카테고리 요약을 무제한으로 계속 쓸 수 있으면 유료 기능을 궁금해할 것이다.
- **H2 (유연한 파서)**: 고정 컬럼 강제 대신 LLM 기반 자동 매핑 + 사용자 확인 화면이면, 카드사/은행마다 다른 CSV 헤더도 큰 마찰 없이 처리할 수 있다.
- **H3 (온보딩 마찰)**: Google OAuth 단일 로그인만으로도 충분히 온보딩할 수 있다.
- **H4 (페이월 경계)**: "카테고리 요약"은 무료, "전월 대비/이상탐지/절약 제안/예산 추천"이 지불 의사를 만든다.
- **H5 (신뢰)**: 금융 데이터를 다루므로 "데이터 처리 방침"(원본 CSV 미저장 등) 메시지가 전환율에 영향을 준다.
- **H6 (처리속도)**: 개인 CSV는 대부분 수천 행 이내라 동기 요청 하나로 처리해도 체감 대기시간이 이탈을 일으킬 정도는 아니다.
- **H7 (모델 단일화)**: Claude 단일 모델로도 리포트 품질이 충분해서, 다른 모델 동시 지원이 MVP 검증 단계의 필수 요소는 아니다.

## MVP 제외 사항
- 여러 CSV 파일 동시 업로드 / 한 파일에 여러 달치가 섞인 경우의 병합 분석
- 모바일 앱
- 이메일/비밀번호 로그인, 비로그인 체험
- 백그라운드 잡 큐 (완전 동기 처리로 대체)
- 모델 선택 UI (Claude 단일 기본값, 프로바이더 추상화만 대비)
- 무료 체험 기간(트라이얼), 다양한 가격 티어
- 카드사/은행별 전용 CSV 파서 사전 정의 (LLM 기반 자동 매핑 + 사용자 확인으로 대체)
- 업로드 횟수 기반 게이팅 (기능 단위 게이팅만 사용)
- Polar 실제 결제 연동 (엔타이틀먼트 스키마만, checkout·webhook은 계정 준비 후 `polar-billing` 후속 phase)
